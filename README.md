# Automobile Dataset - Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on an Automobile dataset to understand the distribution of vehicle characteristics, identify patterns, compare categories, and visualize relationships between important features.

The analysis uses Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn to clean, summarize, and visualize the data.

---

## 🎯 Objectives

- Understand the structure of the automobile dataset.
- Analyze numerical and categorical variables.
- Generate descriptive statistics.
- Visualize feature distributions.
- Compare automobile characteristics across categories.
- Identify trends and patterns using graphical representations.

---

## 📂 Dataset Features

The dataset contains automobile-related attributes such as:

- Fuel Type

- Body Style
- Drive Wheels
- Engine Location
- Engine Type
- Number of Cylinders
- Horsepower
- Peak RPM
- City MPG

- Vehicle Dimensions

## 📊 Analysis Performed

### 1. Data Loading and Inspection

- Loaded dataset using Pandas.
- Displayed sample records.
- Checked dataset dimensions.
- Verified data types.
- Examined missing values.

### 2. Descriptive Statistics

Generated:

- Mean
- Median
- Standard Deviation
- Minimum Value
- Maximum Value
- Quartiles

for numerical columns.

---

### 3. Distribution Analysis

Histogram plots were created to understand the distribution of:

- Price
- Horsepower
- Engine Size
- Mileage-related variables

---

### 4. Categorical Variable Analysis

Bar charts were generated for:

- Fuel Type Distribution
- Engine Type Distribution
- Number of Cylinders
- Aspiration Categories
- Drive Wheel Categories

---

### 5. Comparative Analysis

Compared categories using:

- Grouped Bar Charts
- Stacked Bar Charts
- Frequency Tables

Examples:

- Fuel Type vs Aspiration
- Engine Type vs Number of Cylinders
- Drive Wheels vs Fuel Type

---

### 6. Box Plot Analysis

Box plots were used to detect:

- Outliers
- Spread of Data
- Variability among Categories

---

### 7. Violin Plot Analysis

Violin plots were generated to visualize:

- Distribution Shape
- Density Estimation
- Category-wise Variations
